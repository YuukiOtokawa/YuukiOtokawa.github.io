概要

「FormulaXTactics」は、専門学校3年の制作演習においてチームで開発した、数字カードと関数カードを使用して戦うカードゲーム（ターン制タクティカルカードバトル）です。 各プレイヤーは毎ターン数字カードと関数カードを交互に1枚ずつ場に出し、使用枚数が7枚になったときの計算結果を相手へのダメージとして与えます。 私は仕様書担当として、企画されたゲームシステムを仕様書に落とし込んでタスクとしてまとめ、チームメンバーに割り振るなどのプロジェクトマネジメントを担当しました。

製作期間

約4か月 (3年生の制作演習)

使用技術

ゲームエンジン: Unity 2022.3 LTS 使用言語: C# バージョン管理: Git / GitHub

主な役割

  • 仕様書の構築
    • 仕様書に関しては、書く側が書きやすく、読む側は情報を取り出しやすいような設計を考え、構成を考えました。 具体的には、タスク管理用のタスク表と、各業種ごとのタスク表を用意し、それらを同期させることで、マネージャーは管理しやすく、作業者は自身のタスクの確認をしやすいタスク表を目指しました。
  • チーム内のコミュニケーション
    • 全員が互いの状況を把握し、目指すものを共有するために、制作時間として割り当てられた授業時間は基本的に会議の場としました。 それぞれのタスクの進捗を確認し、不明点や困っていることを相談し、他のメンバーのタスク内容を理解することで、問題が発生した際にチーム内で問題を解決できるように努めました。 自身としても、チーム内でのコミュニケーションの取り方、認識合わせの重要性を学ぶことができました。

    特徴

  • カードシステムの構築
    • カードをマウスドラッグすることで手札からカードを出すと、カードが拡大され、出し終わると縮小される演出を実装。 直感的にカードを扱える操作感を目指しました。
  • 柔軟な効果設計を可能にする追加要素
    • 特定のターン数経過後に手に入るスキルにより、自身や対戦相手のカードや計算結果に影響を与えることができます。 このゲームの特徴である計算の部分がプロトタイプ段階からある程度完成度があった反面、一つのスキルで様々な要素の変更を必要とするため、仕様を考えるのが非常に難しく、タスクの分け方、振り方を悩みながらマネジメントしていました。

    各種ゲームシステム紹介

  • デッキビルディングシステム
    • 何百種類ものカードの中から上限枚数でデッキを構成し、JSON形式でローカルデータに出出力・保存するシステムを設計。 UnityのUIシステム（ScrollRect）を高度にカスタマイズし、サクサクと検索・編成できる画面を作成しました。
  • ターンマネージャーとフェーズ遷移
    • 「ドロー」「メイン」「バトル」「エンド」といった各フェーズの遷移を、状態マシン（Finite State Machine）パターンで完璧に整理。 割り込み効果やチェーン処理など、カードゲーム特有の複雑なイベント順序をバグなく制御しました。
  • シェーダーグラフによる未来エフェクト
    • UnityのShader Graphを活用し、カードがホログラムのようにノイズを走らせて出現するエフェクトや、攻撃時のデジタルグリッド波などを実装。 グラフィックのクオリティを最大限に引き上げました。
