概要

「FormulaXTactics」は、専門学校3年の制作演習においてチームで開発した、近未来的なデジタルカードゲーム（ターン制タクティカルカードバトル）です。 数式や化学式、物理法則といった科学的要素（Formula）をカードの効果に組み込み、プレイヤー同士が知略を競うゲームシステムとなっています。 私はプログラムリーダーとして、ゲームの基礎フレームワークの設計と、デッキ構築システム、ネットワーク同期処理（ローカル対戦ロジックの整理）などを担当しました。 Unityの強力なUIシステムとC#によるロジック記述を活かし、カードの直感的なドラッグ操作やダイナミックな演出を実現しています。

製作期間

約4か月 (3年生の制作演習)

使用技術

ゲームエンジン: Unity 2022.3 LTS 使用言語: C# グラフィック・エフェクト: Shader Graph, Universal Render Pipeline (URP) バージョン管理: Git / GitHub

特徴

  • Unityによる洗練されたカードインタラクション
    • マウスやタッチによるカードのドラッグ＆ドロップ、手札の自動整列、スムーズなホバー演出を独自にコンポーネント化。 物理的なカードを触っているかのような手触り感を追求しました。
  • 柔軟な効果設計を可能にするノード・バフ設計
    • 「攻撃力増加」「ターンごとのダメージ」「特定の条件下で発動」といった多様なカード効果を、C#のインターフェースとクラス継承を駆使してモジュール化。 新カードの追加をパラメータ指定だけで容易に行えるようにしました。
  • タスク管理とリーダーシップ
    • GitHub Projectsを活用してプログラムタスクを細分化し、週次ミーティングを重ねることで開発スピードを維持。 ゲームバランスのテストプレイを頻繁に行い、完成度の向上に努めました。

    各種ゲームシステム紹介

  • デッキビルディングシステム
    • 何百種類ものカードの中から上限枚数でデッキを構成し、JSON形式でローカルデータに出出力・保存するシステムを設計。 UnityのUIシステム（ScrollRect）を高度にカスタマイズし、サクサクと検索・編成できる画面を作成しました。
  • ターンマネージャーとフェーズ遷移
    • 「ドロー」「メイン」「バトル」「エンド」といった各フェーズの遷移を、状態マシン（Finite State Machine）パターンで完璧に整理。 割り込み効果やチェーン処理など、カードゲーム特有の複雑なイベント順序をバグなく制御しました。
  • シェーダーグラフによる未来エフェクト
    • UnityのShader Graphを活用し、カードがホログラムのようにノイズを走らせて出現するエフェクトや、攻撃時のデジタルグリッド波などを実装。 グラフィックのクオリティを最大限に引き上げました。
