概要

「ハコポス!!!」は、専門学校2年の時にチームを組んで制作した、ポップでカジュアルな3D落ちものアクションパズルゲームです。 プレイヤーは上から落ちてくる様々なデザインの可愛い「ハコ（プレゼントボックス）」を回転・移動させ、透明な「ポスト（箱）」の中にきれいに収めて消していくルールとなっています。 私はメインプログラマーとして、Unityの物理演算（Nvidia PhysX）を活かした独自のスタック＆衝突ロジックの構築や、ゲームフロー全体の制御、およびGitHubを使用したソースコードのバージョン管理・競合解消を担当しました。

製作期間

約3か月 (2年生のゲーム制作課題)

使用技術

ゲームエンジン: Unity 2021.3 LTS 使用言語: C# 物理演算: Unity Physics (3D) バージョン管理: Git / GitHub (Git LFS使用)

特徴

  • 物理演算による予測不能な楽しさ
    • 従来のグリッド単位で動くパズルゲームとは異なり、オブジェクトがリアルに転がったり崩れたりする3D物理挙動を実装。 予期しない積み上がり方や大連鎖が起きる、にぎやかでカジュアルなゲーム性を実現しました。
  • GitHubをフル活用したチーム開発
    • デザイナーやプランナーが作成した3Dモデル、UI素材を速やかに統合するため、GitHubを用いたアセット管理フローを整備。 プログラムだけでなくプロジェクト管理の効率化に貢献しました。
  • ポップで分かりやすいビジュアルとエフェクト
    • 箱が弾ける際のおもちゃ箱のような星型のパーティクルや、コンボ数に応じた賑やかなUIアニメーションを実装。 触っているだけで楽しいゲーム体験を目指しました。

    各種ゲームシステム紹介

  • 3D物理コライダーの高度な調整
    • 物理演算による「すり抜け」や「不要な振動」を防ぐため、コライダーの結合（Compound Colliders）や物理マテリアル（摩擦・反発）を緻密に設計。 ストレスのない積み上げ感を実現しました。
  • コンボ＆消去判定アルゴリズム
    • 同じ色や模様の「ハコ」が隣接して3つ以上くっついたことを物理的な接触（OnCollisionEnter / Trigger）と再帰探索（DFS）を用いて検出し、瞬時に消滅させるカスタムアルゴリズムを構築。 3D空間における柔軟なマッチング判定を軽量に実現しました。
  • 動的UIマネージャー
    • ゲームの進行状況（スコアアップ、制限時間アラート、ゲームオーバー）に応じて、UIが弾むように拡大縮小するスクリプトをC#で実装。 プレイヤーのモチベーションを高める演出を施しました。
