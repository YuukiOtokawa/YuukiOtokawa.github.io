概要

「ハコポス!!!」は、専門学校2年の時にチームを組んで制作した、3D落ちものパズルゲームです。 プレイヤーは上から落ちてくる様々な形のハコを回転・移動させ、梱包箱に隙間なく収めて出荷するルールとなっています。 私はGitHub管理者として、GitHubを使用したソースコードのバージョン管理・競合解消を担当しながら、タイトル画面のハコが飛ぶ演出と一部アセットの作成をしました。

製作期間

約5か月(2年次5月~10月)

使用技術

ゲームエンジン: Unity 2022.3.37f1 使用言語: C# バージョン管理: Git / GitHub (Git LFS使用)

特徴

  • 二つの梱包箱に同時に梱包
    • 2つの梱包箱に同時に梱包し、いっぱいになった箱から出荷されていきます。 ちょうどいい形の箱が来なくても、もう一つの箱に収めていくことで欲しい形の箱を待つことができます。
  • 初のチーム開発とGitHub採用
    • 2年次の5月から制作を開始し、10月までの約5か月間で完成させました。 初めてのチームでの制作で、Gitを導入し、アセットの共有やバージョン管理を行いました。 GitHubの扱い方は手探りで調べ、競合解消等でチームメンバーと密に連絡を取り合いながら開発を進めました。 この時のGitHubの経験が、その後の進級制作をはじめ、チーム制作で大いに活かされたと感じています。
  • すべて手作りアセットを使用！
    • 箱もUIもすべて制作メンバーの手作りです。

    各種ゲームシステム紹介

  • 3D物理コライダーの高度な調整
    • 物理演算による「すり抜け」や「不要な振動」を防ぐため、コライダーの結合（Compound Colliders）や物理マテリアル（摩擦・反発）を緻密に設計。 ストレスのない積み上げ感を実現しました。
  • コンボ＆消去判定アルゴリズム
    • 同じ色や模様の「ハコ」が隣接して3つ以上くっついたことを物理的な接触（OnCollisionEnter / Trigger）と再帰探索（DFS）を用いて検出し、瞬時に消滅させるカスタムアルゴリズムを構築。 3D空間における柔軟なマッチング判定を軽量に実現しました。
  • 動的UIマネージャー
    • ゲームの進行状況（スコアアップ、制限時間アラート、ゲームオーバー）に応じて、UIが弾むように拡大縮小するスクリプトをC#で実装。 プレイヤーのモチベーションを高める演出を施しました。
