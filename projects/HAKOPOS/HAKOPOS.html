概要

「ハコポス!!!」は、専門学校2年の時にチームを組んで制作した、3D落ちものパズルゲームです。 プレイヤーは工場の梱包担当となり、コンベアから流れてくる様々な形状の「ハコ」を回転・移動させ、制限時間内に隙間なく詰め込んで出荷する3Dパズルゲームです。 私はGitHub管理者（リポジトリマネージャー）として、Git/GitHubを用いたソースコードのバージョン管理やコンフリクト（競合）解消を担当しました。また開発面では、タイトル画面におけるハコが飛び出す演出の実装や、一部アセットの作成にも貢献しました。

製作期間

約5か月(2年次5月~10月)

使用技術

ゲームエンジン: Unity 2022.3.37f1 使用言語: C# バージョン管理: Git / GitHub (Git LFS使用)

特徴

  • 初のチーム開発とGitHub採用
    • 本作は初めてのチーム制作プロジェクトであり、バージョン管理システムとしてGit/GitHubを導入しました。 手探りの状態からGitHubの運用方法を調べ、競合（コンフリクト）が発生した際にはメンバーと密に連携して解消するなど、円滑な共同開発体制を構築しました。 この開発で得た知見や共同開発の経験は、その後の進級制作など、以降のプロジェクトにおいて非常に大きな強みとなっています。
  • 二つの梱包箱に同時に梱包
    • プレイヤーは2つの梱包箱に対して同時に梱包を進め、完成した箱から順次出荷されていきます。 欲しい形状のハコが来ない場合でも、もう一方の箱に避けるように配置することで、目当てのハコを待つといった戦略的なプレイを可能にしました。
  • すべて手作りアセットを使用！
    • ゲーム内に登場するハコや各種UIは、アセットストア等の外部素材に頼らず、制作メンバーの手によって一から作成された完全オリジナルアセットを使用しています。
