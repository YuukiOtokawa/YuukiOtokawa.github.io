概要

「祓魔犬」は、専門学校2年の進級制作としてチームで制作した、和風ダークファンタジー世界観の2D横スクロールアクションゲームです。 プレイヤーは霊力を持った黒い犬「祓魔犬」となり、襲い来る妖怪たちを退治しながら進みます。 私はプログラム全般と、チームの進行管理（スケジュール管理）を担当しました。 DirectX11をベースに自作のフレームワークを使用し、滑らかなアクションと躍動感のあるエフェクトの描画にこだわりました。

製作期間

約6か月 (2年生の進級制作)

使用技術

使用言語: C++ (ゲームロジック、描画制御), HLSL (エフェクト・描画用シェーダー) グラフィックAPI: DirectX11 ツール: Git / GitHub (バージョン管理・進行管理), Redmine (タスク管理)

特徴

  • 少人数チームでの徹底した進行管理
    • ガントチャートやRedmineを用い、企画から実装完了までのタスクの可視化と遅延対策を徹底。 各メンバーの得意分野に合わせたアサインを行い、予定通りの期間内にクオリティの高いゲームを完成させました。
  • DirectX11による自作2Dエンジン
    • スプライト描画、コリジョン判定、アニメーション制御、パーティクルシステムなどをDirectX11上で実装。 描画負荷を最小限に抑えつつ、ダイナミックなアクションを実現しました。
  • 和風ダークファンタジーを彩る演出
    • 日本古来の妖怪が登場するダークな世界観を、独特のカラーフィルターとエフェクトで演出。 主人公（犬）の滑らかな走りや攻撃アニメーションに合わせた残像・火花エフェクトをシェーダー側で細かく調整しました。

    各種ゲームシステム紹介

  • プレイヤー（祓魔犬）のアクション制御
    • ダッシュ、壁キック、連続コンボ攻撃などの軽快なアクションを実装。 状態遷移（ステートパターン）をきれいに設計することで、バグを抑え柔軟なアクションの追加を可能にしました。
  • エフェクトシステム
    • パーティクルを大量に発生させるためのバッファ管理と、頂点シェーダーを利用した高速描画を実装。 斬撃の軌跡や、敵を倒した際の光の霧散などを美麗に表現しています。
  • ステージマネージャーとコリジョン
    • 矩形や円、線分による当たり判定を独自実装。 地形データと敵オブジェクト、プレイヤーのインタラクションを高度に最適化し、めり込みのないスムーズな移動を実現しました。
