概要

「妖怪探偵」は、専門学校3年の夏休みからチームを組んで制作している、和風ノベルアドベンチャーゲームです。 プレイヤーは探偵となり、人間と妖怪が共存する不思議な街で巻き起こる奇妙な事件の謎を解き明かしていきます。 私はプログラム全般と、GitHubを使用したプロジェクト全体のリポジトリ管理・ブランチ戦略の構築を担当しました。 Unity上で動作する高度なテキストアドベンチャーエンジンを構築し、ストーリーの分岐や演出を柔軟にコントロールできるシステムを実現しています。

製作期間

2025年8月 〜 現在進行中 (3年生の夏休みから開始)

使用技術

ゲームエンジン: Unity 2022.3 LTS 使用言語: C# データ設計: ScriptableObject / JSON バージョン管理: Unity Version Control

特徴

  • Live2Dによるキャラクターアニメーション
    • Cubism Unity SDKの導入により、Live2Dアニメーションを表示するシステムを構築。 2Dで描かれたキャラクターをデザイナーの思い通りに動かすことができるようになりました。
  • CSVファイルによるシナリオ読み込み
    • CSVファイルで表示されるキャラクターのアニメーションやテキストデータを管理 テキストデータを編集するだけでゲーム内に反映されるため、プログラマーでなくてもシナリオの追加や変更が容易にできるようになりました。 また、シナリオにIDを振り、シナリオごとに次のシナリオIDを指定しておくことで、テキストデータだけで複雑なシナリオ分岐を構築できるようになりました。 探索中に人に話しかけるなどのイベントが発生すると、そのイベントに対応したシナリオIDに遷移し、イベントシーンが始まる仕組みになっています。
  • アドベンチャーゲームっぽいテキスト表示
    • 会話テキストを表示する際、1文字ずつ表示することでゲームらしい演出を実現 また、表示中にマウスの左クリックをすると即座に全てのテキストを表示する機能も実装 アドベンチャーゲームらしく自動送りやログ表示の機能も実装

    各種ゲームシステム紹介

  • 証言・証拠管理（インベントリ）システム
    • 探索や会話によって得られた「証拠品」や「証言」をScriptableObjectで一元管理し、いつでも手帳画面で閲覧できるシステムを構築。 特定の会話イベントで正しい証拠を提示する（突きつける）ロジックを汎用化しました。
  • 会話イベントパーサー
    • エクセル等で記述されたシナリオデータをJSON経由でパースし、イベントキューに入れて1つずつ実行する仕組みを実装。 「キャラクター切り替え」「背景変更」「効果音再生」といった多様なコマンドをテキストデータだけで指示できるようになりました。
  • フラグ管理＆分岐システム
    • プレイヤーの選択肢や調査した場所によって変化する何百ものイベントフラグを、Bit配列やハッシュマップを用いて軽量・安全にセーブ＆ロードする機能を実装。 バッドエンドや真エンドへのルート分岐を正確にコントロールします。

    今後の展望・実装したい機能

  • プレイヤーの探索パートを強化する「3D捜査モード」の統合
