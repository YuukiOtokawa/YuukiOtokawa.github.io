概要

「妖怪探偵」は、専門学校3年の夏休みからチームを組んで制作している、和風レトロな雰囲気のミステリーアドベンチャーゲームです。 プレイヤーは探偵となり、人間と妖怪が共存する不思議な街で巻き起こる奇妙な事件の謎を解き明かしていきます。 私はプログラム全般と、GitHubを使用したプロジェクト全体のリポジトリ管理・ブランチ戦略の構築を担当しました。 Unity上で動作する高度なテキストアドベンチャーエンジンを構築し、ストーリーの分岐や演出を柔軟にコントロールできるシステムを実現しています。

製作期間

2025年8月 〜 現在進行中 (3年生の夏休みから開始)

使用技術

ゲームエンジン: Unity 2022.3 LTS 使用言語: C# データ設計: ScriptableObject / JSON バージョン管理: Git / GitHub (Git Flowベースのブランチ運用)

特徴

  • 独自のノベル・アドベンチャーエンジン
    • テキストの表示速度制御、ルビ対応、立ち絵フェード、BGM・SEの再生などを一括で制御する強力なイベント管理スクリプトを構築。 シナリオファイル（JSON）を読み込むだけで複雑な演出が自動再生されるシステムを実現しました。
  • 確実なGitブランチ運用による衝突防止
    • チーム開発におけるUnityのシーンやプレハブの競合を未然に防ぐため、Git Flowをベースにした機能単位のブランチ運用ルールを策定。 Pull Requestによる相互レビュー体制を作り、コード品質の担保を行いました。
  • ミステリアスな和風の世界観を彩る演出
    • レトロでミステリアスな街の雰囲気を表現するため、2Dイラストの立ち絵と3D背景のライティングを緻密に調整。 妖怪が出現する際のおどろおどろしいエフェクトや画面の歪み演出をUnityのPost-Processingで実装しました。

    各種ゲームシステム紹介

  • 証言・証拠管理（インベントリ）システム
    • 探索や会話によって得られた「証拠品」や「証言」をScriptableObjectで一元管理し、いつでも手帳画面で閲覧できるシステムを構築。 特定の会話イベントで正しい証拠を提示する（突きつける）ロジックを汎用化しました。
  • 会話イベントパーサー
    • エクセル等で記述されたシナリオデータをJSON経由でパースし、イベントキューに入れて1つずつ実行する仕組みを実装。 「キャラクター切り替え」「背景変更」「効果音再生」といった多様なコマンドをテキストデータだけで指示できるようになりました。
  • フラグ管理＆分岐システム
    • プレイヤーの選択肢や調査した場所によって変化する何百ものイベントフラグを、Bit配列やハッシュマップを用いて軽量・安全にセーブ＆ロードする機能を実装。 バッドエンドや真エンドへのルート分岐を正確にコントロールします。
